# Отчёт по практике Lesson CI

## Прогноз до изменения ссылки на таблицу

Если заменить `href="style.css"` на `href="missing.css"`, тест `test_stylesheet_exists` должен завершиться ошибкой `Missing stylesheet: missing.css`, поскольку такого файла в `site/` нет. Шаги `Build site` и `Save site artifact`, расположенные после проверки, должны быть пропущены.

## Запуски

Ожидают выполнения в GitHub Actions: исходный успешный запуск, запуск с ошибкой, запуск после восстановления ссылки и запуск после изменения аудитории. Ссылки, SHA и фактические строки журнала будут внесены после проверки.

## Проверки

Job `check-build` выполняется на выделенном GitHub runner с `ubuntu-latest`. GitHub Actions сохраняет результат и журнал запуска в репозитории. Шаг `Save site artifact` сохраняет собранные файлы как артефакт `lesson-site`; это не публикация сайта в интернете.

## Изменение аудитории

Прогноз: замена номера аудитории с 301 на 302 не должна сломать текущие тесты, потому что они проверяют заголовок, тему и наличие файла стилей, но не правильность номера аудитории. Зелёный результат поэтому не доказывает, что номер аудитории указан верно.
